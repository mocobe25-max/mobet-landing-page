# Mobet Landing Page

A comprehensive React/TypeScript gaming and betting platform with multiple game types, user management, admin dashboards, and multi-language support.

## Features

### Games
- **Crash Game** - Fast-paced crash prediction game
- **Dice Game** - Traditional dice rolling game
- **Mines Game** - Strategy-based mines game
- **Apple of Fortune** - Spin-to-win fortune game

### User Features
- User authentication and authorization
- Deposit and withdrawal system
- Transaction history
- User dashboard
- Settings management
- Multi-language support (i18n)
- Push notifications

### Admin Features
- Admin dashboard for platform management
- Agent dashboard for sub-admin management
- Financial reports and analytics
- User management

## Tech Stack

- React 18+ with TypeScript
- Supabase (PostgreSQL)
- PWA Support
- Multi-language support

## Installation

```bash
npm install
cp env.example .env.local
npm run dev
```
